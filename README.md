# STM32F411-Using-Push-Button-LED-Blynk-
Implemented push button-controlled LED operation using the STM32F411VE microcontroller, STM32CubeIDE, Embedded C, and the STM32 HAL library. Configured GPIO pins to read button input and control LED output.

Technologies Used:
- Microcontroller: STM32F411VE (ARM Cortex-M4)
- IDE: STM32CubeIDE
- Programming Language: Embedded C
- Library: STM32 HAL
- Peripherals: GPIO Input and GPIO Output
